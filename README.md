# AppSafe - Verified Mobile Mod & Tweak Directory

[![Cloudflare Pages](https://img.shields.io/badge/Deployed%20with-Cloudflare%20Pages-f38020?logo=cloudflare&logoColor=white)](https://appsafe-9xj.pages.dev)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

Official web application for **AppSafe**, the curated directory for verified mobile modifications, tweaks, and utility packages for iOS and Android.

## Features
- **49 Curated Applications & Tweaks:** Detailed technical specifications, device compatibility guides, and virus verification.
- **Universal Search Engine:** Real-time fuzzy matching with typo tolerance, single-letter instant filtering, and international Unicode diacritics normalization.
- **Responsive Dark Design:** Fast, mobile-first design with `#00ff88` neon accents.
- **SEO & AI Citability:** Pre-rendered HTML, structured Schema.org JSON-LD, comprehensive `sitemap.xml`, and `llms.txt`.
- **Integrated Content Locker:** Direct delivery integration for verified package installations.
